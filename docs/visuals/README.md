# KEEL Visuals

Canonical visual references for the KEEL project.

These assets are kept together so documentation and repository root stay clean.

| Asset | Purpose |
|---|---|
| `keel-logo.png` | KEEL brand mark and horizontal lockup |
| `keel-workflow.png` | Controlled engineering workflow |
| `keel-system-model.png` | KEEL system model and control layer |
| `keel-internal-agent-topology.png` | Internal agent topology and role orchestration |
| `keel-architecture.png` | High-level KEEL architecture and system layers |

The visual set is intentionally separate from implementation documentation. Changes to these assets should preserve the established KEEL visual language and information architecture.
