# Skills - `~/.omp/agent/skills/`

Каталог для скилов. Один скил = одна папка с `SKILL.md`:

```
~/.omp/agent/skills/<имя-скила>/SKILL.md
```

Вложенные группы (`skills/группа/<скил>/SKILL.md`) omp НЕ обнаруживает - только один уровень.

Имя и описание каждого найденного скила попадают в системный промпт всех агентов, а тело
подтягивается по требованию через `read skill://<имя>`. Отдельно, во frontmatter агента, можно
указать `autoloadSkills: ["имя"]` - тогда тело скила вливается в его контекст ДО первого промпта
(это для скилов, которые агент применяет всегда; неизвестные имена omp безопасно игнорирует).

Подсказки с готовым синтаксисом уже стоят закомментированными в `agents/coder.md`,
`agents/reviewer.md` и `agents/designer.md`.
