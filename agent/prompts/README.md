# Prompts - `~/.omp/agent/prompts/`

Каталог для переиспользуемых промпт-шаблонов omp. Харнесс своих не поставляет: вся его
операционка живёт в трёх слоях инструкций (`AGENTS.md`, `APPEND_SYSTEM.md`, `RULES.md`) и в телах
агентов, а текущий этап пайплайна расширение впрыскивает в контекст само, каждый ход.

Каталог оставлен пустым намеренно - под твои собственные шаблоны.
